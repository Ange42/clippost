Publish your edited short videos to TikTok

ClipPost is a small desktop tool used by our editing team. It uploads short vertical videos that we have edited ourselves to the TikTok accounts we own, with the caption written by the editor.

How it works

  1. The account owner signs in once with Login Kit and authorizes ClipPost (scopes user.info.basic, video.upload, video.publish).
  2. ClipPost shows the connected account (display name and avatar) and the privacy levels TikTok allows for it.
  3. For each finished video, the user checks the preview, writes the caption, chooses who can view it and confirms. ClipPost then sends it through the Content Posting API.
  4. ClipPost checks the publishing status and shows the result. The user can revoke access at any time in TikTok settings.

Who uses it

Only our own team, on our own TikTok accounts. ClipPost is not offered to the public and does not access anyone else's account.
