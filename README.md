# ClipPost

Internal tool that publishes our edited short videos to our own TikTok accounts with TikTok Login Kit and the Content Posting API.

- `tiktok.py`: command line tool (connect an account, check allowed settings, publish a video).
- `docs/`: public website (home, Terms of Service, Privacy Policy) served by GitHub Pages.

Secrets (`secrets/tiktok_app.json`, tokens) are never committed.
