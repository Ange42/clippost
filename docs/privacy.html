Privacy Policy

Last updated: November 24, 2026

1. What ClipPost is

ClipPost is an internal tool that publishes videos edited by our team to TikTok accounts we own, using TikTok Login Kit and the Content Posting API.

2. Data we receive from TikTok

  • Basic profile information (user.info.basic): open ID, display name and avatar, used only to show which account is connected.
  • OAuth access and refresh tokens, used only to publish the videos the user confirms.
  • Creator settings returned by TikTok (allowed privacy levels, maximum video length), used to show valid options before posting.
  • The publishing status of each video we send.

3. How we store it

Tokens and settings are stored locally on the computer that runs ClipPost, in a private folder. They are never sold, shared or sent to any server other than TikTok's.

4. What we do not do

  • We do not read followers, messages, likes or any other account data.
  • We do not access accounts other than the ones that authorize ClipPost.
  • We do not use the data for advertising or profiling.

5. Retention and deletion

Data is kept only while the account stays connected. You can revoke ClipPost at any time in TikTok (Settings › Security › Manage app permissions); the local tokens are then deleted. You can also ask us to delete them using the contact link below.

6. Children

ClipPost is not intended for anyone under 18.

7. Changes

We will update this page if this policy changes.
